# Feature 2.9 — Verified Link Management & Verification API Documentation

> **Portal**: Owner & Verifier  
> **Base Path**: `/api/v1`  
> **Auth**: `Authorization: Bearer <JWT_TOKEN>`  
> **Feature**: Shareable Credential Verification Links (Ticket 2.9)

---

## Overview

Feature 2.9 enables Credential Owners to generate short-lived, rate-limited, and org-restricted shareable **Verification Codes** for their claimed credentials. Verifiers can submit these codes to instantly inspect credential details without requiring persistent access.

---

## 1. Owner Portal Endpoints

### 1.1 Create Verification Code

> **`POST /api/v1/owner/verified-links`**  
> **Summary**: `[Owner] Create Verification Code`  
> **Auth**: Owner JWT (`Authorization: Bearer {{owner_access_token}}`)

Generates a new shareable 12-character verification code for a claimed credential. The plaintext code is returned **ONCE** in the response and is never stored in plaintext (hashed using SHA-256).

#### Request Body
```json
{
  "credential_id": "6a796d47930eebede514ce0d",
  "expires_at": "2026-12-31T23:59:59Z",
  "allowed_org_ids": ["60b9f1d2e4b0a1a2b3c4d5e6"],
  "max_access_count": 5
}
```

| Field | Type | Required | Description |
|---|---|---|---|
| `credential_id` | String (ObjectId) | **Yes** | ID of the claimed credential owned by the user |
| `expires_at` | String (ISO 8601) | No | Expiration datetime (must be in the future). Default: `null` (no expiration) |
| `allowed_org_ids` | Array[String] | No | Allowed Verifier Org IDs. Default: `[]` (any verifier) |
| `max_access_count` | Integer | No | Maximum number of successful verifications allowed (`>= 1`). Default: `null` (unlimited) |

#### Response `201 Created`
```json
{
  "success": true,
  "data": {
    "id": "66b9f1d2e4b0a1a2b3c4d5e7",
    "code": "A9K3X7M2P4Q8",
    "credential_id": "6a796d47930eebede514ce0d",
    "expires_at": "2026-12-31T23:59:59Z",
    "allowed_org_ids": ["60b9f1d2e4b0a1a2b3c4d5e6"],
    "max_access_count": 5,
    "remaining_access_count": 5,
    "display_status": "active",
    "created_at": "2026-08-10T04:15:00Z",
    "revoked_at": null
  },
  "message": "Verification code created successfully.",
  "error_code": null
}
```

#### Error Responses
- `404 CREDENTIAL_NOT_FOUND` — Credential does not exist or is not owned by the requester
- `400 CREDENTIAL_NOT_CLAIMED` — Credential is not in `claimed` status
- `400 INVALID_EXPIRATION` — `expires_at` is in the past
- `400 INVALID_ACCESS_COUNT` — `max_access_count` < 1

### 1.2 List Verification Codes

> **`GET /api/v1/owner/verified-links`**  
> **Summary**: `[Owner] List Verification Codes`  
> **Auth**: Owner JWT (`Authorization: Bearer {{owner_access_token}}`)

Fetches a paginated list of verification codes created by the owner with derived display statuses.

#### Query Parameters
- `credential_id` *(optional string)*: Filter by specific credential ID
- `page` *(optional integer, default `1`)*: Page number
- `page_size` *(optional integer, default `20`)*: Items per page (max 100)

#### Response `200 OK`
```json
{
  "success": true,
  "data": {
    "items": [
      {
        "id": "66b9f1d2e4b0a1a2b3c4d5e7",
        "credential_id": "6a796d47930eebede514ce0d",
        "expires_at": "2026-12-31T23:59:59Z",
        "allowed_org_ids": ["60b9f1d2e4b0a1a2b3c4d5e6"],
        "max_access_count": 5,
        "remaining_access_count": 4,
        "display_status": "active",
        "created_at": "2026-08-10T04:15:00Z",
        "revoked_at": null
      }
    ],
    "total": 1,
    "page": 1,
    "page_size": 20
  },
  "message": null,
  "error_code": null
}
```

> **Display Status Values**:
> - `"active"`: Code is valid and usable
> - `"expired"`: Code has passed its `expires_at` date
> - `"exhausted"`: `remaining_access_count` has reached 0
> - `"revoked"`: Code was manually revoked by the owner

### 1.3 Edit Verification Code

> **`PATCH /api/v1/owner/verified-links/{link_id}`**  
> **Summary**: `[Owner] Edit Verification Code`  
> **Auth**: Owner JWT (`Authorization: Bearer {{owner_access_token}}`)

Updates expiration, allowed verifier orgs, or max access count for an **active** verification code.

#### Request Body
*(All fields are optional; only provided fields are updated)*
```json
{
  "expires_at": "2027-01-15T00:00:00Z",
  "allowed_org_ids": [],
  "max_access_count": 10
}
```

#### Response `200 OK`
```json
{
  "success": true,
  "data": {
    "id": "66b9f1d2e4b0a1a2b3c4d5e7",
    "expires_at": "2027-01-15T00:00:00Z",
    "allowed_org_ids": [],
    "max_access_count": 10,
    "remaining_access_count": 9,
    "display_status": "active",
    "updated_at": "2026-08-10T05:00:00Z"
  },
  "message": "Verification code updated successfully.",
  "error_code": null
}
```

#### Error Responses
- `404 VERIFIED_LINK_NOT_FOUND` — Link ID not found or not owned by requester
- `400 LINK_ALREADY_REVOKED` — Link has been revoked by the owner
- `400 LINK_EXPIRED` — Link has passed its expiration date
- `400 LINK_EXHAUSTED` — Link remaining access count has reached 0

---

### 1.4 Revoke Verification Code

> **`DELETE /api/v1/owner/verified-links/{link_id}/revoke`**  
> **Summary**: `[Owner] Revoke Verification Code`  
> **Auth**: Owner JWT (`Authorization: Bearer {{owner_access_token}}`)

Immediately revokes a verification code, rendering it permanently unusable.

#### Response `200 OK`
```json
{
  "success": true,
  "data": {
    "id": "66b9f1d2e4b0a1a2b3c4d5e7",
    "status": "revoked",
    "revoked_at": "2026-08-10T05:10:00Z"
  },
  "message": "Verification code revoked.",
  "error_code": null
}
```

#### Error Responses
- `404 VERIFIED_LINK_NOT_FOUND` — Link ID not found or not owned by requester
- `400 LINK_ALREADY_REVOKED` — Link is already revoked
- `400 LINK_EXPIRED` — Cannot revoke a link that has already expired
- `400 LINK_EXHAUSTED` — Cannot revoke a link whose access count is exhausted

## 2. Verifier Portal Endpoints

### 2.1 Verify Code

> **`POST /api/v1/verifier/verified-links/verify`**  
> **Summary**: `[Verifier] Verify a Code`  
> **Auth**: Verifier Institution Account JWT (`Authorization: Bearer {{verifier_access_token}}`)

Verifies a 12-character plaintext code, checks all security restrictions, atomically decrements remaining access count, logs access history, and returns credential details.

#### Request Body
```json
{
  "code": "A9K3X7M2P4Q8"
}
```

#### Response `200 OK` — Success Payload
```json
{
  "success": true,
  "data": {
    "credential": {
      "id": "6a796d47930eebede514ce0d",
      "full_name": "Elon Musk",
      "student_id": "C333",
      "major": "Computer Science",
      "graduation_year": 2026,
      "classification": "Excellent",
      "degree_type": "Bachelor",
      "issuer_org_id": "60b9f1d2e4b0a1a2b3c4d500"
    },
    "verified_at": "2026-08-10T05:20:00Z"
  },
  "message": "Credential verified successfully.",
  "error_code": null
}
```

#### Response `200 OK` — Denial Payloads
*(Note: Verification denials return HTTP 200 with `success: false` and standard structured error codes for clean UI rendering)*

```json
{
  "success": false,
  "data": null,
  "message": "The verification code is invalid.",
  "error_code": "INVALID_VERIFICATION_CODE"
}
```

| Denial Reason | `error_code` | `message` |
|---|---|---|
| Code not found / invalid | `INVALID_VERIFICATION_CODE` | "The verification code is invalid." |
| Link manually revoked | `LINK_REVOKED` | "This verification link has been revoked by the owner." |
| Link passed `expires_at` | `LINK_EXPIRED` | "This verification link has expired." |
| Access count exhausted | `LINK_EXHAUSTED` | "This verification link has reached its maximum access count." |
| Verifier org not in `allowed_org_ids` | `UNAUTHORIZED_VERIFIER` | "Your organization is not authorized to use this verification link." |
| Underlying credential revoked | `CREDENTIAL_REVOKED` | "The credential associated with this verification link has been revoked." |
